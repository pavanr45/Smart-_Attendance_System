# Smart Attendance System

## Description
Developed a **Student Attendance System** using **Java**, **Spring Boot**, **Hibernate**, **Angular**, and **MySQL** to simplify and streamline attendance tracking in educational institutions.

## Technologies Used
- Java
- Spring Boot
- Hibernate
- MySQL
- Angular
- Postman (for API testing)

## Features
- Role-based access for students and faculty
- Real-time attendance recording
- RESTful API integration between backend and frontend
- Secure data handling with Hibernate and MySQL
